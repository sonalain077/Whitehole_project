## Adjudicator

The decisions in `cases.csv` were made by **the coding agent (Claude)** at the user's
request, not by a human. The column is called `human_decision` to stay compatible
with the tool; every note starts with `agent;`. Safeguards and limits:

- The definitions applied are those of the assignment (page 4), restated in `GUIDE.md`.
- `GUIDE.md` and `cases.csv` do not show which version proposed what, and `key.json`
  was opened only after scoring. The adjudication is not fully blind, however: the
  agent had already seen, in conversation, some versions' labels for N039, N047, N091
  and N095.
- It is a different model from `gpt-5.6-terra`, hence a different family of errors,
  but it is not human ground truth.
- 21 decisions are marked `debatable`: a reasonable annotator could decide otherwise.
  The user read the reasoning for R004 (PCG), R008-R009 (AMZN, HD) and R013 (ADBE),
  found them debatable but defensible, and approved the whole set without changing a
  decision.
